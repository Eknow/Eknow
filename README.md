## Sobre mí

Soy desarrollador **Frontend** con +3 años construyendo aplicaciones web de uso real en producción.

Me especializo en **React**, dashboards administrativos y **flujos multipaso** con reglas de negocio complejas. Me gusta dejar la lógica de dominio clara, testeable y separada de la UI — no solo “pantallas bonitas”, sino producto que aguanta el día a día.

- 🎓 **Universidad Tecnológica de Durango** — Desarrollo y Gestión de Software (egreso 2025)
- 💼 **Eficaz Digital (Cura)** — Frontend en plataforma educativa / administrativa
- 🛡️ Colaboré en **Escudo Vecinal** (web + móvil) — sistema de incidencias ciudadanas
- 🚀 Lideré el módulo de **preinscripciones** de punta a punta
- 🔭 Hoy: seguir creciendo como Frontend Mid (producto, arquitectura, calidad)
